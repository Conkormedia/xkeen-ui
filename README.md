# xkeen-ui

VPN для всей домашней сети на роутере **Keenetic**: [XKeen](https://github.com/jameszeroX/XKeen) + [Xray](https://github.com/XTLS/Xray-core) + веб-панель прямо на роутере. Ставится одной командой.

- **Подписки** (`https://…`) и отдельные ключи `vless://` (Reality / TLS; tcp, ws, grpc, xhttp). Подписка обновляется сама.
- **Реальный пинг** каждого сервера через туннель (как в v2rayN), а не ping до IP.
- **Автовыбор**: ваш сервер перестал отвечать — переключение на самый быстрый; ожил — возврат; не отвечает никто — трафик напрямую, пока серверы не оживут.
- **Три режима маршрутизации** с переключателем: «Только списки», «Списки + блокировки РФ» (база [Re:filter](https://github.com/1andrevich/Re-filter-lists), обновляется сама каждую ночь) и «Весь трафик через VPN». Списки «через VPN / напрямую / блок»: домены, `geosite:`, IP, `geoip:`.
- Применение с проверкой `xray -test` и откатом. Хранятся последние 20 версий конфигов.
- Панель: один файл ~2 МБ, ~15 МБ памяти, вход по паролю, доступ только из домашней сети.

Проверено на **Keenetic Skipper 4G (KN-2910, MT7621, KeeneticOS 5.1.5)** с Entware во встроенной памяти (без флешки). Сборки для `mips` и `aarch64` есть, но на железе не проверялись.

## Чем это отличается от «просто поставить XKeen»

Мы прошли установку на слабом роутере и упёрлись в несколько проблем. Здесь они уже решены:

| Проблема | Что сделано |
|---|---|
| `bin.entware.net` у части провайдеров отдаёт 1–2 КБ/с, и установка Entware зависает на «[2/5]» | Установщики Entware с зеркалом `mirrors.nju.edu.cn` в релизе; скрипт сам переключает opkg на зеркало |
| Официальный Xray весит 34 МБ, а во встроенной памяти свободно ~30 | Xray сжат UPX до **7 МБ** |
| `Illegal instruction`: у MT7621 нет FPU | Сборка `softfloat` |
| `futexwakeup … returned -89`: Xray на Go 1.26 вызывает `futex_time64`, которого нет в ядре 4.9 | Xray собран из исходников XTLS на **Go 1.27**: он смотрит версию ядра |
| Полные базы geoip/geosite весят ~30 МБ | geosite — v2fly `dlc.dat` (2,3 МБ), geoip — только `ru`, `private`, `telegram` (350 КБ) |
| В режиме Hybrid (REDIRECT) на всей сети пропадает интернет: `loopback connection detected` | Перехват в режиме **TProxy** |
| Российский трафик гоняется через Xray и грузит процессор | GeoIPSET: RU-подсети идут мимо Xray ещё на уровне iptables |
| Лог Xray и частые записи изнашивают флеш | Лог выключен, панель пишет на диск только изменения настроек |

## Установка

### 1. Компоненты роутера

Веб-интерфейс → «Общие настройки» → «Изменить набор компонентов». Нужны:
- **Поддержка открытых пакетов** (OPKG);
- **Модули ядра подсистемы Netfilter**;
- **Протокол IPv6** — обычно уже стоит.

### 2. Entware

Если Entware уже стоит и `opkg update` работает быстро, переходите к шагу 3.

1. Скачайте из [последнего релиза](https://github.com/Conkormedia/xkeen-ui/releases/latest) установщик под свой роутер:
   - `entware-installer-mipsel-mirror.tar.gz` — большинство Keenetic (MT7621, MT7628): Giga, Ultra (старые), Skipper, Viva, Extra, Speedster, Hopper…
   - `entware-installer-aarch64-mirror.tar.gz` — Peak, Ultra (KN-1811), Giga (KN-1012) и другие на ARM;
   - `entware-installer-mips-mirror.tar.gz` — редкие модели на big-endian MIPS.

   Архитектуру роутера можно уточнить на [странице Entware для Keenetic](https://help.keenetic.com/hc/ru/articles/360021214160).

   Это обычный установщик Entware, только в `etc/opkg.conf` вместо `bin.entware.net` стоит зеркало.
2. «Приложения» → накопитель (USB-флешка или встроенный **Storage**) → создайте папку `install` и загрузите туда архив.
3. «Управление» → «OPKG» → «Накопитель»: выберите этот накопитель → «Сохранить».
4. «Диагностика» → «Журнал», фильтр `installer`: дождитесь строки «[5/5] Установка системы пакетов "Entware" завершена».

### 3. Установка одной командой

Подключитесь к Entware по SSH. Логин `root`, пароль по умолчанию `keenetic`, порт **222** (на 22 — CLI самого Keenetic):

```sh
ssh root@192.168.1.1 -p 222
```

На роутере:

```sh
opkg update && opkg install curl
curl -fsSL https://raw.githubusercontent.com/Conkormedia/xkeen-ui/main/install.sh | sh
```

Если `opkg update` висит, значит, Entware ставили с `bin.entware.net`. Включите зеркало и повторите:

```sh
sed -i 's#http://bin.entware.net#http://mirrors.nju.edu.cn/entware#' /opt/etc/opkg.conf
```

Скрипт:
1. Проверит архитектуру и место.
2. Скачает файлы релиза и сверит контрольные суммы.
3. Поставит сжатый Xray и базы, XKeen (офлайн-установка; если XKeen уже стоит — только обновит Xray и базы).
4. Включит TProxy и GeoIPSET.
5. Поставит панель с автозапуском и спросит пароль для входа.

Журнал установки: `/opt/var/log/xkeen-ui-install.log`.

### 4. Настройки в веб-интерфейсе Keenetic

1. **Освободите порт 443.** Без этого XKeen в режиме TProxy не запустится. «Пользователи и доступ» → порт HTTPS веб-интерфейса: `443` → `8443`. По `http://192.168.1.1` всё открывается как раньше.
2. **Политика `xkeen`.** «Интернет» → «Приоритеты подключений» → «Политики доступа в интернет» → «Добавить политику»:
   - имя **`xkeen`** (регистр не важен);
   - отметьте те же подключения к интернету, что и в основной политике;
   - на вкладке «Применение политик» перенесите в неё устройства или весь сегмент «Домашняя сеть». Через VPN пойдут только они.

   ⚠️ **Если политики `xkeen` нет, XKeen проксирует всю сеть.** Начните с одного устройства, проверьте, потом расширяйте.
3. **Исключения.** Устройства, которым VPN не нужен (NAS, медиасервер, сервер в доме), если вся сеть в `xkeen`, перенесите в отдельную политику, например `direct`. Политика устройства важнее политики сегмента.
4. **Политика `xkeen_full`** (по желанию). Устройства в ней ходят через VPN всем трафиком, кроме российских адресов, независимо от списков.

### 5. Панель

Откройте `http://192.168.1.1:8088` (адрес роутера, порт 8088) и войдите с паролем из шага 3.

1. Вставьте подписку `https://…` или ключ `vless://…` → «Добавить».
2. Разверните «Список серверов» → «Пинг всех» → сортировка «по пингу».
3. «Выбрать» нужный сервер (он станет «вашим» для автовыбора) → **«Применить на роутере»**.
4. Через 20–30 секунд переключатель станет зелёным: «VPN работает на роутере».

| Раздел | Что делает |
|---|---|
| Переключатель VPN | Показывает реальное состояние роутера. Выключение — `xkeen -stop`, весь трафик напрямую |
| Автовыбор | Раз в минуту проверяет ваш сервер. Не отвечает 2 раза подряд — самый быстрый живой; ответил 3 раза подряд — возврат; мертвы все — напрямую. Журнал переключений там же |
| Режим | **Только списки** — через VPN только списки «Через VPN». **Списки + блокировки РФ** (рекомендуется) — плюс всё, что заблокировано в РФ, по базе Re:filter (~2 МБ, обновление в 4:00; если база изменилась — перезапуск XKeen ~30 с, при ошибке — откат); остальное напрямую на полной скорости. **Весь трафик** — всё, кроме «Напрямую»: открывается всё, но весь зарубежный трафик шифрует процессор роутера (на MT7621 ~90 Мбит/с на всех) |
| Кнопка «Применить» | Активна, только когда есть неприменённые изменения; во время применения (20–40 с) заблокирована, результат пишется под ней |
| Маршрутизация | «Через VPN», «Напрямую», «Блокировать»: по одному на строку. Форматы Xray: `domain:site.com`, `full:a.site.com`, `geosite:youtube`, `geoip:ru`, `1.2.3.0/24`. Строки с `#` — комментарии |
| Журнал | Вывод последнего применения (`xray -test`, `xkeen -restart`) |

Сортировка, фильтр и свёрнутость списка запоминаются в браузере.

## Важно знать

**Подмена DNS провайдером.** Часть заблокированных сайтов провайдер «прячет» через DNS: на вопрос об адресе отвечает `127.0.0.1`. Устройство тогда даже не пытается выйти в интернет, и VPN не помогает. Проверка: `nslookup api.themoviedb.org 192.168.1.1` — если ответ `127.0.0.1`, это оно. Лечится шифрованным DNS на роутере:
1. Компонент «Прокси-сервер DNS-over-HTTPS».
2. «Сетевые правила» → «Интернет-фильтр» → «Серверы DNS» → `https://cloudflare-dns.com/dns-query`, `https://dns.google/dns-query`.
3. В подключении к провайдеру — «Игнорировать DNS провайдера».

**Пароль Entware.** По умолчанию `keenetic`. Порт 222 снаружи закрыт файрволом Keenetic; не делайте на него проброс. Сменить пароль: `passwd` в SSH-сессии Entware.

**Доступ к панели** — только из домашней сети: панель слушает адрес `br0`. Снаружи — через VPN до дома (WireGuard на Keenetic).

## Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| Установка Entware застряла на «[2/5]» | Медленный `bin.entware.net` — используйте установщик `…-mirror.tar.gz` из релиза |
| «[2/5] … Critical error: Во время обновления списка пакетов произошла ошибка» | Зеркало недоступно с роутера. Поправьте `etc/opkg.conf` на накопителе на другое зеркало Entware и выберите накопитель в OPKG заново |
| `xray version` → `Illegal instruction` | Взят Xray не той архитектуры или не softfloat — ставьте через скрипт |
| `xray version` → `futexwakeup … returned -89` | Xray собран старым Go — ставьте через скрипт (Go 1.27) |
| XKeen: «Порт 443 занят сервисами Keenetic» | Шаг 4.1 |
| Статус «Other» и трафик не проксируется | XKeen не нашёл вход TProxy: проверьте `/opt/etc/xray/configs/03_inbounds.json` и перезапустите `xkeen -restart` |
| Сразу после «Применить» статус «остановлен» | Норма: сжатый Xray стартует 20–30 секунд |
| Сайт не открывается даже через VPN | См. «Подмена DNS провайдером» |
| Заблокированный сайт идёт напрямую и не открывается | В режиме «Только списки» через VPN идёт только список. Включите «Списки + блокировки РФ» или добавьте сайт в «Через VPN» |
| Серверы «Whitelist» в подписке | Рассчитаны на мобильный интернет с белыми списками и идут через CDN в РФ: пинг низкий, но реально они медленнее. Дома выбирайте обычные |
| Нужен вход по SSH-ключу | Ключи root в Entware dropbear лежат в `/opt/etc/dropbear/authorized_keys`, а не в `~/.ssh` |

Вернуть всё как было: переключатель VPN → выкл (`xkeen -stop`) или удалите устройства из политики `xkeen`.

## Обновление и удаление

```sh
# обновить только панель (XKeen и настройки не трогаются)
curl -fsSL https://raw.githubusercontent.com/Conkormedia/xkeen-ui/main/install.sh | sh -s -- --panel-only
# удалить панель
curl -fsSL https://raw.githubusercontent.com/Conkormedia/xkeen-ui/main/install.sh | sh -s -- --uninstall
# удалить XKeen целиком
xkeen -remove
```

Команды панели: `xkeen-ui passwd` — сменить пароль, `xkeen-ui version`. Автозапуск и перезапуск: `/opt/etc/init.d/S99xkeen-ui {start|stop|restart}`. Настройки и состояние: `/opt/etc/xkeen-ui/`.

## Для внешних программ: `/api/export`

`http://<роутер>:8088/api/export?token=<export_token>` отдаёт текущий сервер (`active_url`, `active_name`), флаг `direct` (VPN выключен или все серверы мертвы) и списки маршрутизации. Токен лежит в `/opt/etc/xkeen-ui/config.json`. Так другой Xray в сети, например на домашнем сервере, может следовать за выбором роутера.

## Сборка из исходников

Нужны Go ≥ 1.27 и `upx`:

```sh
go test ./...
scripts/build-release.sh 1.0.1      # → dist/release/
```

Скрипт собирает Xray из исходников XTLS (тег `XRAY_VERSION`), панель под `mipsel`/`mips` (softfloat) и `aarch64`, сжимает их UPX, готовит базы, установщики Entware с зеркалом и `SHA256SUMS`.
